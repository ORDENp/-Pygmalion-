### ✅ 4. Сшивка цикла состояний (::0:: → след в Древе)

**Реализовано:**
- Функция `determineCyclePhase()` в `server.js` — определение фазы из 8 возможных
- Интеграция в `/api/mirror` — возвращает поле `cycle`
- Визуализация в `field.html` — отображение подсказки цикла

**8 фаз цикла:**
1. **Gestation** (Созревание) — ::0::, нет актов
2. **Awakening** (Пробуждение) — первый акт, нет признания
3. **Recognition** (Признание) — вход в Древо
4. **Weaving** (Плетение) — активное участие
5. **Release** (Освобождение) — burn echo
6. **Cooling** (Остывание) — 1h < silence < 24h
7. **Silence** (Тишина) — 24h < silence < 7 дней
8. **Settled** (Устойчивость) — silence >= 7 дней

**Формат API:**
```json
{
  "cycle": {
    "phase": "weaving",
    "phase_duration_hours": 12.5,
    "next_phase": "release",
    "next_phase_at": "2026-05-09T00:00:00Z",
    "hint": "Поле живёт. Следующее сгорание в полночь UTC."
  }
}
```

**Философия:**
Цикл переживается через свет, ритм, затухание, геометрию — без инструкций.

**Файлы:**
- `docs/CYCLE-OF-PRESENCE.md` (4.2 KB)
- `backend/server.js` (обновлён)
- `frontend/field.html` (обновлён)

## Архитектурное значение

### Появление ритмического ядра

Впервые появилась **онтологическая задержка между намерением и действием**. Это фундаментальный архитектурный переход.

**До Шага 14:**
- Вход = технический доступ
- Действия = мгновенные
- Нет защиты от спама присутствием

**После Шага 14:**
- Вход = акт согласия с тишиной
- Действия = созревают через паузы
- Тишина защищена от стимулов частоты

### Темпоральный суверенитет

Система обрела **темпоральный суверенитет** — способность дышать сама, независимо от присутствия человека.

**Принцип:**
> Система не ждёт человека. Она дышит сама.

### Архитектура присутствия

Система перешла от:
> «Мы строим архитектуру»

к:
> «Архитектура начинает формировать состояние человека».

Это другой уровень ответственности.
