## Цель

Создать минимальное переживание связности — не граф-аналитику, а **ощущение присутствия в поле**.

## Реализация

**Файл:** `frontend/field.html`

**Технологии:**
- Canvas 2D API (без библиотек)
- Vanilla JavaScript
- Fetch API для `/api/field/:ok_id`

---

## Архитектура присутствия (сохранена)

### Что НЕ показывается

- ❌ Числа на экране
- ❌ Подписи узлов
- ❌ Метрики (degree, centrality)
- ❌ Рейтинги
- ❌ Выделенный "центр важности"

### Что показывается

- ✅ Узлы (self/other) — без подписей
- ✅ Связи (кривые Безье) — не прямые линии
- ✅ У.М. как свечение — не значки
- ✅ Поле "дышит" — фоновая пульсация
- ✅ Мягкая физика — отталкивание + притяжение

## Визуальные эффекты

### Узлы

- **Размер:** self (12px), other (8px) — не зависит от "важности"
- **Цвет:** self (белый), other (светло-серый)
- **Пульсация:** мягкая, зависит от времени и позиции
- **Свечение:** радиальный градиент вокруг узла

### Рёбра

- **Форма:** кривые Безье (quadraticCurveTo)
- **Цвет по типу:**
  - RECOGNITION → золотистый (rgba(255,200,100,0.4))
  - FLOW → синий (rgba(100,150,255,0.3))
  - CAUSAL → серый (rgba(150,150,150,0.2))
- **Толщина:** 1-2px
- **Анимация:** мягкое колебание контрольной точки

### У.М. (Учётные Маркеры)

- **Форма:** свечение на середине ребра
- **Цвет по marker_type:**
  - value → золотистый
  - gratitude → оранжевый
  - alignment → синий
  - witness → серебристый
  - support → зелёный
- **Интенсивность по witness_scope:**
  - personal → 0.6
  - observation → 0.4
  - indirect → 0.2
- **Анимация:** пульсация (Math.sin)

### Поле (field)

#### connections (sparse|woven|dense)
- Влияет на начальное расположение узлов
- sparse → больше разброс
- dense → узлы ближе

#### activity (quiet|active|resonant)
- Влияет на фоновое дыхание:
  - quiet → 0.02
  - active → 0.04
  - resonant → 0.08

## Физика

### Отталкивание между узлами

```javascript
const repulsion = 0.02;
const force = repulsion / (dist * dist);
```

### Притяжение по рёбрам

```javascript
const attraction = 0.01;
const force = (dist - 0.3) * attraction;
```

### Затухание

```javascript
const damping = 0.85;
node.vx *= damping;
node.vy *= damping;
```

### Мягкие границы

```javascript
if (Math.abs(node.x) > 0.8) node.vx *= -0.5;
if (Math.abs(node.y) > 0.8) node.vy *= -0.5;
```

## Поведение

### Узлы

- Плавают (мягкая физика)
- Отталкиваются друг от друга
- Притягиваются по рёбрам
- Пульсируют

### Связи

- Дышат (колебание контрольной точки)
- Не прямые (кривые Безье)
- Цвет зависит от типа

### У.М.

- Появляются как свечение
- Пульсируют
- Интенсивность зависит от witness_scope

### Поле

- Дышит (фоновая пульсация)
- Интенсивность зависит от activity

---

## Граница канона

### Что проверено

- ✅ Нет чисел на экране
- ✅ Нет подписей узлов
- ✅ Нет метрик (COUNT, SUM)
- ✅ Нет рейтингов
- ✅ Связи — кривые, не прямые
- ✅ У.М. — свечение, не значки
- ✅ Поле дышит

### Что НЕ реализовано (намеренно)

- ❌ Hover-эффекты (риск превращения в граф-аналитику)
- ❌ Клик на узлы (риск выделения "важных")
- ❌ Фильтры (риск аналитики)
- ❌ Zoom/pan (пока не нужно)
- ❌ Подписи (нарушает канон)

## Следующие шаги

### Если прототип "заживёт"

1. **WebGL** — если появится плотность графа (>500 узлов)
2. **Hover** — очень осторожно, без нарушения канона
3. **Временные слои** — trace (история присутствия)
4. **Directions** — визуализация векторов (given/received/burned)

### Если нужно углубить

1. **Алгоритм раскладки** — без "центров власти"
2. **Shader-слой** — мягкое свечение + blur (WebGL)
3. **Stream событий** — реальное время

## Технические детали

### Координаты

- Нормализованные (-1 до 1)
- Преобразование в экранные через `toScreen(x, y)`
- Центр экрана = (0, 0)

### Анимация

- `requestAnimationFrame` (60 FPS)
- Счётчик времени `t` для пульсаций
- Физика обновляется каждый кадр

### Производительность

- Canvas 2D достаточно для <100 узлов
- Нет сложных вычислений
- Нет DOM-манипуляций
