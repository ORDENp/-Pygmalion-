## Технические детали

### Debounce для автозагрузки

```javascript
let loadTimeout;
document.getElementById('ok_input').addEventListener('input', () => {
  clearTimeout(loadTimeout);
  loadTimeout = setTimeout(loadField, 800);
});
```

**Результат:** Загрузка происходит через 800ms после последнего изменения input.

### Минимальные статусные сообщения

```javascript
const statusParts = [];
if (state.trace.face_window !== 'silent') statusParts.push(state.trace.face_window);
if (state.trace.form_hint !== 'emerging') statusParts.push(state.trace.form_hint);
if (state.trace.burn_echo?.active) statusParts.push('echo');

document.getElementById('field_status').textContent = statusParts.join(' · ') || '—';
```

**Результат:** Статус показывает только ключевые состояния, без избыточных деталей.

### i18n автоматическое обновление DOM

```javascript
updateDOM() {
  document.querySelectorAll('[data-i18n]').forEach(el => {
    const key = el.getAttribute('data-i18n');
    const translation = this.t(key);

    if (el.hasAttribute('data-i18n-html')) {
      el.innerHTML = translation;
    } else {
      el.textContent = translation;
    }
  });
}
```

**Результат:** Все элементы с data-i18n атрибутами обновляются автоматически при смене языка.
