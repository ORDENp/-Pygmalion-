## Контекст

Шаг 10.6 завершает переход от наблюдения за эффектом (Шаг 10.5) к **архитектурному стандарту**, где временное (ЛИЦО) и устойчивое (ОБЛИК) разделены на уровне физики и данных.

Ключевое усиление: связка с **Абсолютным нулём (::0::)** и структурная проверка ro.DAG, чтобы ОБЛИК не превратился в простую усреднённую статистику.

## Выполненные задачи

### 1. Модернизация логики API `/api/field` ✅

**Файл:** `backend/server.js`

#### Контур ЛИЦО (face_window)

Автоматическое определение состояния на основе `silence_hours`:

```javascript
if (silence_hours < 4) face_window = 'alive';
else if (silence_hours < 28) face_window = 'cooling';
else face_window = 'silent';
```

**Состояния:**
- `alive` — < 4 часов после последнего акта
- `cooling` — 4–28 часов (фаза затухания импульса)
- `silent` — > 28 часов (после работы Метронома)

#### Контур ОБЛИК (form_hint)

Внутренняя проверка устойчивости связей в `ro_dag_edges` **без вывода чисел наружу**:

```sql
-- Подсчёт подтверждённых рёбер (RECOGNITION, FLOW)
SELECT COUNT(DISTINCT edge_id) FILTER (WHERE edge_type IN ('RECOGNITION', 'FLOW'))

-- Подсчёт повторяющихся связей
SELECT COUNT(*) FROM (
  SELECT connection, COUNT(*) as cnt
  GROUP BY connection
  HAVING COUNT(*) > 1
)

-- Время стабильности структуры
SELECT NOW() - MAX(created_at) FROM ro_dag_edges
```

**Состояния:**
- `emerging` — < 3 подтверждённых рёбер RECOGNITION или FLOW
- `steady` — наличие повторяющихся связей между одними и теми же О.К. или внутри одной Триады
- `settled` — структура графа не менялась более 120 часов (5 циклов), несмотря на акты BURNED

#### Состояние ::0:: (Абсолютный ноль)

Если в `acts_log` для данного О.К. нет ни одной записи:

```json
{
  "state": "absolute_zero",
  "nodes": [],
  "edges": [],
  "acts": [],
  "trace": {
    "face_window": "silent",
    "form_hint": "emerging",
    "burn_echo": { "active": false }
  }
}
```

**Смысл:** Это не "отсутствие данных" — это **состояние до первого акта**. Потенциальность, ещё не проявленная.

### 2. Обновление Canvas-физики `frontend/field.html` ✅

#### Анимация ЛИЦА

**alive:**
- Высокочастотная пульсация узлов (pulse * 0.2, speed 0.1)
- Яркие импульсы по рёбрам (faceImpulse * 0.25)
- Активный дрейф узлов (jitter ±3px)
- Интенсивное фоновое дыхание (intensity 0.12)

**cooling:**
- Замедленная пульсация (pulse * 0.1, speed 0.04)
- Слабые импульсы по рёбрам (faceImpulse * 0.12)
- Минимальный дрейф (jitter ±1.5px)
- Мягкое фоновое дыхание (intensity 0.06)

**silent:**
- Статичные узлы (pulse = 1.0, jitter = 0)
- Импульсы отсутствуют (faceImpulse = 0)
- Минимальное фоновое дыхание (intensity 0.02)

#### Геометрия ОБЛИКА

**emerging:**
- Свободное движение узлов (attraction = 0.01)
- Нормальное затухание (damping = 0.85)

**steady:**
- Усиленное притяжение по рёбрам (attraction = 0.015)
- Нормальное затухание (damping = 0.85)

**settled:**
- **Кристаллизация** — узлы стремятся к фиксированным координатам
- Усиленное притяжение (attraction = 0.03)
- Усиленное затухание (damping = 0.7) — минимизация дрейфа
- Целевые координаты (targetX, targetY) фиксируются при первом settled

```javascript
// Кристаллизация — притяжение к целевым координатам
if (isSettled) {
  for (const node of state.nodes) {
    if (node.targetX !== null) {
      const dx = node.targetX - node.x;
      const dy = node.targetY - node.y;
      const force = 0.05;
      node.vx += dx * force;
      node.vy += dy * force;
    }
  }
}
```

#### Абсолютный ноль (::0::)

**Визуализация:**
- Пустое тёмное поле (rgba(10,10,15,1))
- Надпись `::0::` в центре (rgba(255,255,255,0.1))
- Нет узлов, рёбер, анимации

## Архитектурное значение

Этот шаг завершает переход от **"визуализации данных"** к **"архитектуре присутствия"**.

Система теперь явно различает:
- **Временное** (face_window) — что живёт в моменте (alive/cooling/silent)
- **Устойчивое** (form_hint) — что живёт во времени (emerging/steady/settled)
- **Потенциальное** (absolute_zero) — что ещё не проявлено

Это не просто визуальный эффект. Это **фундаментальное свойство архитектуры**, зафиксированное в протоколе ::про.3.КОЛ::.
