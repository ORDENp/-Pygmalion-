## Контекст

После наблюдения траектории затухания (Шаг 10) было обнаружено фундаментальное свойство системы:

**ЛИЦО уходит, ОБЛИК остаётся.**

После сгорания (BURN) текущее движение обнуляется, но геометрия связей в ro.DAG сохраняет устойчивость.

Этот шаг переводит наблюдаемый эффект в статус **архитектурного принципа**.

## Выполненные задачи

### 1. Модернизация API `/api/field` ✅

**Файл:** `backend/server.js`

**Изменения:**

Расширен объект `trace` с разделением на два контура:

```json
{
  "trace": {
    "last_act_at": "2026-05-06T14:00:00Z",
    "silence_hours": 6.1,
    "face": {
      "phase": "cooling",
      "intensity": "fading"
    },
    "shape": {
      "stability": "forming",
      "persistence_hours": 48.5
    },
    "burn_echo": {
      "active": false,
      "phase": "release"
    }
  }
}
```

**ЛИЦО (face):**
- `phase` — фаза движения (`alive` | `cooling` | `silent`)
- `intensity` — интенсивность (`present` | `fading` | `absent`)

**ОБЛИК (shape):**
- `stability` — стабильность структуры (`forming` | `settled`)
- `persistence_hours` — время жизни структуры (с момента первого ребра в ro.DAG)

**Burn Echo:**
- `active` — активен в течение 1 часа после работы Метронома
- `phase` — всегда `"release"` (момент выдоха)

**Логика фаз:**
- `alive` — silence < 1h → `intensity: present`
- `cooling` — 1h < silence < 24h → `intensity: fading`
- `silent` — silence > 24h → `intensity: absent`

**Логика стабильности:**
- `forming` — persistence < 168h (7 дней)
- `settled` — persistence >= 168h

### 2. Обновление визуализации `frontend/field.html` ✅

**Изменения:**

#### Разделение визуальных слоёв

**ЛИЦО (анимация):**
- Пульсация узлов зависит от `face.intensity`
- Дрейф (jitter) узлов при `intensity: present`
- Импульсы по рёбрам при активности
- Фоновое дыхание поля

**ОБЛИК (геометрия):**
- Статичная геометрия рёбер (кривые Безье без дрейфа)
- Постоянное базовое свечение узлов и рёбер
- Расстояния между узлами не меняются при затухании

**Burn Echo:**
- Краткий импульс расслабления поля (волна свечения)
- Активируется на 1 час после сгорания

#### Код (примеры)

**Пульсация узлов (ЛИЦО):**
```javascript
let pulse = 1.0;
if (state.trace.face?.intensity === 'present') {
  pulse = 1 + Math.sin(t * 0.05 + node.x * 10) * 0.15;
} else if (state.trace.face?.intensity === 'fading') {
  pulse = 1 + Math.sin(t * 0.03 + node.x * 10) * 0.08;
}
```

**Дрейф узлов (ЛИЦО):**
```javascript
let jitter = { x: 0, y: 0 };
if (state.trace.face?.intensity === 'present') {
  jitter.x = Math.sin(t * 0.03 + node.x * 5) * 2;
  jitter.y = Math.cos(t * 0.03 + node.y * 5) * 2;
}
```

**Постоянное свечение (ОБЛИК):**
```javascript
const baseOpacity = 0.4; // Не зависит от активности
const shapeGlow = 0.02;  // Постоянное базовое свечение
```

**Burn Echo:**
```javascript
let burnEchoEffect = 0;
if (state.trace.burn_echo?.active) {
  burnEchoEffect = Math.sin(t * 0.1) * 0.15;
}
```

**При `face.intensity: present`:**
- Узлы пульсируют быстро (pulse * 0.15)
- Узлы дрейфуют (jitter ±2px)
- Импульсы по рёбрам видны (faceImpulse * 0.2)
- Фоновое дыхание активно (intensity 0.08)

**При `face.intensity: fading`:**
- Узлы пульсируют медленно (pulse * 0.08)
- Узлы дрейфуют слабо (jitter ±1px)
- Импульсы по рёбрам слабые (faceImpulse * 0.1)
- Фоновое дыхание замедлено (intensity 0.04)

**При `face.intensity: absent`:**
- Узлы статичны (pulse = 1.0, jitter = 0)
- Импульсы отсутствуют (faceImpulse = 0)
- Фоновое дыхание минимально (intensity 0.02)
- **ОБЛИК остаётся:** геометрия рёбер, базовое свечение

**При `burn_echo.active: true`:**
- Краткий импульс расслабления (burnEchoEffect * 0.15)
- Волна свечения по всему полю

## Архитектурное значение

Этот шаг завершает переход от **"набора протоколов"** к **"единому полю присутствия"**.

Система теперь явно различает:
- **Временное** (ЛИЦО) — что живёт в моменте
- **Устойчивое** (ОБЛИК) — что живёт во времени

Это не просто визуальный эффект. Это **фундаментальное свойство архитектуры**.
