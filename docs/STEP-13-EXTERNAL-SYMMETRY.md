### 3. Визуальный и институциональный фильтр ✅

**Файл:** `frontend/field.html`

#### Визуальный вес узла ::00:: (Предстоятель)

**Проблема:** Предстоятель не должен восприниматься как "центр власти" или доминирующая метрика.

**Решение:**
```javascript
// Проверка на Предстоятеля (::00::) — ствол Древа
const isPredstoyatel = node.id === '::00::';

// Предстоятель (::00::) — ствол, не доминирующий центр
if (isPredstoyatel) {
  radius = 9; // Средний размер, не максимальный
}

// Цвет — нейтральный, без доминирования
if (isPredstoyatel) {
  color = `rgba(200,200,200,${opacity * 0.9})`;
}
```

**Результат:**
- ::00:: воспринимается как "ствол" (точка начала)
- Размер средний (9px), не максимальный
- Цвет нейтральный (серый), без визуального доминирования
- Нет специального glow или выделения

#### Состояние ::0:: (Gestation)

**Проверка:** Визуализация передаёт потенциал, а не пустоту.

**Подтверждено:**
- Центральный узел с слабым мерцанием (gestationPulse)
- Узел имеет массу, но не имеет вектора
- Минимальный glow (потенциальность)
- Надписи "::0::" и "gestation" с низкой opacity
- Очень медленное дыхание (t * 0.01)

**Смысл:** Состояние покоя и созревания, а не отсутствия.
