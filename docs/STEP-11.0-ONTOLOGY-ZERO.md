### 1. Активация состояния ::0:: в API ✅

**Файлы:** `backend/server.js` (endpoints `/api/field` и `/api/mirror`)

#### Логика перехода в ::0::

**Условие 1:** О.К. не имеет ни одного акта в `acts_log`
```javascript
const hasActs = parseInt(hasActsResult.rows[0].count) > 0;
if (!hasActs) {
  return res.json({ state: 'absolute_zero', reason: 'no_acts', ... });
}
```

**Условие 2:** О.К. не совершал передач У.Е. (TRANSFER) или У.М. (RECOGNITION) в течение 90 дней
```sql
SELECT MAX(created_at) as last_activity
FROM (
  SELECT created_at FROM acts_log
  WHERE actor_ok = $1 AND act_type = 'TRANSFER'
  UNION ALL
  SELECT al.created_at FROM acts_annotations aa
  JOIN acts_log al ON aa.act_ref_id = al.act_id
  WHERE aa.author_ok = $1 AND aa.annotation_type = 'RECOGNITION'
) AS significant_acts
```

```javascript
const inactivity_days = (Date.now() - new Date(last_activity).getTime()) / (1000 * 60 * 60 * 24);
if (inactivity_days >= 90) {
  return res.json({ state: 'absolute_zero', reason: 'inactivity_90_days', ... });
}
```

#### Что сохраняется при переходе в ::0::

**Важно:** История не удаляется. Это защищает других участников НОД-платформы.

- ✅ Все акты в `acts_log`
- ✅ Все рёбра в `ro_dag_edges`
- ✅ Все У.М. в `acts_annotations`

#### Что возвращает API

**Для нового О.К. (no_acts):**
```json
{
  "state": "absolute_zero",
  "reason": "no_acts",
  "nodes": [],
  "edges": [],
  "trace": {
    "last_act_at": null,
    "silence_hours": null,
    "face_window": "silent",
    "form_hint": "emerging"
  }
}
```

**Для неактивного О.К. (inactivity_90_days):**
```json
{
  "state": "absolute_zero",
  "reason": "inactivity_90_days",
  "last_activity_at": "2025-11-07T12:00:00Z",
  "inactivity_days": 181.5,
  "trace": {
    "last_act_at": "2025-11-07T12:00:00Z",
    "silence_hours": 4356.0
  }
}
```

### 2. Документирование онтологии ✅

**Файл:** `docs/ONTOLOGY-ABSOLUTE-ZERO.md`

#### Вертикаль бытия

```
::i:: (Дух)
  ↓
::0:: (Абсолютный ноль)
  ↓
::про.1:: — ::про.24:: (Протоколы)
```

**::i:: (Дух):**
- Невидимая основа системы
- Источник смысла
- Философская основа, определяющая "почему"

**::0:: (Абсолютный ноль):**
- Состояние чистого присутствия
- Потенциальность до первого акта
- Покой после 90 дней без передач

**::про.1:: — ::про.24:: (Протоколы):**
- Конкретные механизмы взаимодействия
- Реализованы в коде

#### Иерархия Духа — Орден ::01::

**Предстоятель (::00::):**
- Хранитель канона
- Решающий голос (::33::) при патовых ситуациях (50/50)
- Не имеет права единоличного решения

**Орден ::01:: (Хранители чистоты):**
- Образовательно-управленческий базис
- Хранители канона и протоколов
- Наставники новых участников
- Решения принимаются большинством (>50%)

**Вход в Орден:**
- Минимум 1 год активного участия
- Минимум 100 передач У.Е.
- Минимум 50 У.М. от разных участников
- Одобрение текущего состава (>66%)

**Смысл:** Орден ::01:: — это не элита, а **служение**.

#### Древо Инициаторов

**Определение:** Структура связей доверия, отражённая в ro.DAG через рёбра RECOGNITION.

**Визуализация:** "Ветки" признания в Canvas показывают геометрию доверия.

**Правила:**
- Древо не превращается в рейтинг
- Нет "топ-10" или "самых влиятельных"
- Визуализация показывает форму, а не количество

## Архитектурное значение

Шаг 11.0 устанавливает **точку тишины**, из которой родится новый Облик системы.

**Абсолютный ноль (::0::)** — это не конец, а **начало**. Это:
- Потенциальность до первого акта
- Покой после 90 дней без передач
- Онтологическая основа для всех протоколов

**Вертикаль ::i:: → ::0:: → ::про.1::-::про.24::** фиксирует философскую основу системы.

**Орден ::01::** устанавливает образовательно-управленческий базис без узурпации власти.

**Летопись:** свидетельствует о рождении технологии ТУТумУЕ / ТИУП(ч).
